## Criterio de mantenimiento

- Un archivo por día, con nombre `AAAA-MM-DD.md` y hora de corte.
- Incorporar novedades sin duplicar ni eliminar evidencias previas. Identificar correcciones y ampliaciones.
- Separar trabajos del día y arrastres posteriores al corte anterior, conservando la fecha real.
- Si no existe actividad comprobable, registrar «Sin cambios verificados».
- Incluir resumen, cambios por módulo, verificaciones y resultados, entregas, pendientes y evidencias. Nunca incluir contraseñas o credenciales.
- Horario inicial de la automatización: diariamente a las 17:00 de Venezuela. Identificador: `informe-diario-de-cambios-ster`.
- Los informes registran el trabajo; no autorizan modificar la app, instalar APK ni sincronizar o alterar bases de datos.
